# 🖼️ Image Converter

Converta, comprima e redimensione imagens diretamente no navegador.

O processamento acontece localmente no dispositivo do usuário através da Canvas API, sem envio de arquivos para servidores, garantindo mais privacidade e velocidade.

---

## 🚀 Acessar

https://encryptkalean.github.io/image-converter/

---

## ✨ Funcionalidades

- 📤 Upload de imagens diretamente do dispositivo.
- 🔄 Conversão entre PNG, JPEG, WEBP e AVIF.
- 📏 Redimensionamento por escala.
- 🎚️ Controle de qualidade/compressão.
- ⚡ Processamento local no navegador.
- 👀 Comparação visual entre imagem original e convertida.
- 📊 Comparação de tamanho, formato e resolução.
- 📥 Download imediato da imagem convertida.
- 📱 Interface responsiva para desktop e dispositivos móveis.

---

## 🔒 Privacidade

Nenhum arquivo é enviado para servidores.

Toda a conversão é realizada localmente no navegador utilizando a Canvas API e recursos nativos do JavaScript.

## 📈 Recursos implementados

- Conversão assíncrona de imagens
- Gerenciamento de memória com `URL.revokeObjectURL()`
- Suporte a tema claro e escuro
- Suporte a redução de animações (`prefers-reduced-motion`)
- SEO otimizado (Open Graph, Twitter Cards e Schema.org)
- Interface acessível com navegação por teclado
